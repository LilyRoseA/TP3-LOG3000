# Calculatrice Web avec Flask

**Numéro d’équipe :** 4 (Lily-Rose Arès - 2377089 et Thierry Poulin - 2330561)

## Objectif

Créer une calculatrice accessible depuis un navigateur. L’application permet de saisir une expression mathématique et d’en afficher le résultat. Elle est développée en Python avec Flask.

## Prérequis

- Python 3 installé
- `pip`, le gestionnaire de paquets de Python

## Installation et démarrage

1. Ouvrir un terminal dans le dossier du projet.
2. Installer Flask :

   ```bash
   python -m pip install Flask
3. Démarrer l'application
   ```bash
   python app.py
4. Ouvrir l'adresse suivante dans le navigateur
   http://localhost:5000
